# 네이버 파워링크 · 파워컨텐츠 순위 체크

로그인한 네이버 계정 기준(연령·성별 타겟팅 반영)으로 검색 결과 화면의 **파워링크**와 **파워컨텐츠**(화면 표기: "'키워드' 관련 브랜드 콘텐츠") 노출 순위를 PC/모바일별로 확인합니다.

- 파워링크: `-t 도메인`으로 매칭 (표시 URL 또는 랜딩 URL에 포함되면 내 광고)
- 파워컨텐츠: 화면에 URL이 없고 **광고주 브랜드명**만 보이므로 `--pc-target 브랜드명`(대시보드: "내 브랜드명")으로 매칭. 비우면 도메인으로 시도
- 파워컨텐츠는 정보성 키워드에만 노출됩니다. 영역 자체가 없으면 "영역 없음"으로 표시

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `login.py` | 네이버 로그인. `--set 아이디 비번`으로 계정 저장(로컬), 이후 세션 만료 시 자동 재로그인 |
| `run.py` | **매일 실행용**: `settings.json` 설정으로 순위 체크 1회 (PowerShell: `python run.py`) |
| `rank.py` | 순위 체크 본체 |
| `common.py` | 공통 설정 |
| `keywords.txt` | 검색할 키워드 목록 (한 줄에 하나, `#`으로 시작하면 무시) |
| `대시보드.bat` | **더블클릭 → 웹 대시보드** (http://127.0.0.1:8765). 키워드 입력·실행·결과·추이를 화면에서 관리 |
| `app.py` / `web/index.html` | 대시보드 서버와 화면 |
| `settings.json` | 대시보드에서 저장한 키워드(파워링크/파워컨텐츠 각각)·도메인·브랜드명·옵션. `run.py`도 이 설정을 사용 |
| `순위체크.bat` | 더블클릭 → `run.py` 실행 (대시보드 설정 기준) |
| `results_YYYYMMDD.csv` | 실행 결과 (날짜별로 자동 생성, 같은 날은 누적) |
| `순위요약_YYYY-MM.xlsx` | **엑셀 요약** (월별 1개, 상위 폴더). 시트 1개(순위): 실행시각 · 구분 · 키워드 · PC순위 · MO순위 · 비고. 회차마다 파워링크(keywords 순) 바로 아래 파워컨텐츠(pc_keywords 순)가 이어져 PC·MO 열을 그대로 복사·붙여넣기 (2026-10-13) |
| `summary.py` | 엑셀 요약 생성 (키워드 순서 = settings.json 순서) |
| `paste.py` / `붙여넣기.bat` | 최신 실행분 파워컨텐츠 순위를 settings.json 의 pc_keywords 순서로 클립보드에 복사 (PC·MO 두 열, 탭 구분). 매 실행 후 `붙여넣기_최신.txt` 도 자동 갱신 |
| `자동순위체크.bat` | 작업 스케줄러(매일 09:00·16:00)용. 창 없이 실행, 로그는 `logs\YYYYMMDD.log` |

`-t` 도메인을 지정했는데 1페이지에 없으면 자동으로 **파워링크 '더보기' 전체 목록**(PC 25개/페이지, 모바일 15개씩 더보기)을 끝까지 훑어 순위를 찾습니다. 끄려면 `--no-deep`.

로그인 세션은 `C:\Users\멤버용\AppData\Local\naver_powerlink\profile` 에 저장됩니다 (OneDrive에 안 올라감).

## 로그인 (자동)

`%LOCALAPPDATA%\naver_powerlink\credentials.json` 에 저장된 계정으로 **세션이 만료되면 자동으로 다시 로그인**합니다 ('로그인 상태 유지' 체크 포함).
쿠키가 파일에 있는지가 아니라 **naver.com 서버가 세션을 인정하는지**를 매 실행 시작 때 확인하므로, 미로그인 상태(연령·성별 타겟팅 빠짐 → 실제 화면과 다른 순위)로 검색하는 일이 없습니다.
대시보드 상단 배지와 실행 로그 첫 줄에 **로그인한 아이디**가 표시됩니다 (비밀번호는 어디에도 노출되지 않음).

- 계정 저장/변경: `python login.py --set 아이디 비밀번호`
- 저장된 계정으로 지금 로그인: `python login.py` (credentials.json이 없으면 수동 로그인 창이 뜸)

## 사용법 ① 웹 대시보드 (권장)

1. `대시보드.bat` 더블클릭 → 검은 콘솔 창이 뜨고 브라우저가 자동으로 열립니다 (콘솔 창은 닫지 말고 두세요)
2. **파워링크 키워드**와 **파워컨텐츠 키워드**를 각각 입력(달라도 됨), 내 광고 도메인·브랜드명 입력 → **순위 체크 시작**
3. 진행 로그가 실시간으로 보이고, 끝나면 "최근 결과"에 파워링크 표 / 파워컨텐츠 표가 따로 나옵니다 (키워드 | PC순위 | MO순위)
   - 각 표의 **"표 복사"** 버튼 → 엑셀/스프레드시트에 바로 붙여넣기 (숫자만 복사, 더보기 순위도 숫자로)
   - 숫자 칸의 색: 초록=첫 화면, 노랑=더보기 목록 순위, 회색=미노출/영역 없음
4. 로그인이 풀리면 상단 **네이버 로그인 창 열기** 버튼으로 다시 로그인

끝낼 때는 콘솔 창을 닫으면 됩니다. 결과는 여전히 `results_YYYYMMDD.csv`에 저장되므로 엑셀로도 열 수 있습니다.

## 사용법 ② PowerShell (매일 실행)

```powershell
cd "C:\Users\멤버용\OneDrive\ai프로젝트\ai프로젝트_claude\01.뷰성형외과\01.순위담당"
python run.py            # 대시보드에 저장된 설정(settings.json) 그대로 1회 실행. 세션 만료 시 자동 로그인
python run.py --show     # 브라우저 창을 보면서 실행
```

`순위체크.bat` 더블클릭도 같은 동작입니다. 결과는 `results_YYYYMMDD.csv`(원본)와 `순위요약_YYYY-MM.xlsx`(엑셀 요약, 세로 누적)에 저장되고 대시보드에서도 바로 보입니다.
엑셀 요약 파일을 엑셀에서 열어둔 채 실행하면 그 회차는 `순위요약_YYYY-MM_HHMM.xlsx`로 따로 저장되고, 다음 실행 때 자동으로 합쳐집니다.

### 개별 옵션으로 직접 실행

```powershell
cd "C:\Users\멤버용\OneDrive\ai프로젝트\ai프로젝트_claude\01.뷰성형외과\01.순위담당"
python login.py                                   # 저장된 계정으로 로그인 (평소엔 불필요)
python rank.py -f keywords.txt -t 내도메인.com     # PC+모바일, 내 광고 순위 요약
python rank.py 다이어트 "강남 피부과" -d mobile     # 키워드 직접 입력, 모바일만
python rank.py -f keywords.txt --headless          # 브라우저 창 없이
```

옵션: `-d pc|mobile|both` (기본 both), `-t 도메인`, `--pc-target 브랜드명`, `--pc-file 파워컨텐츠전용키워드.txt`, `--types powerlink,powercontents`(기본 둘 다), `-o 결과파일.csv`, `--delay 초`(키워드 간 대기, 기본 3), `--headless`, `--no-deep`

## 결과 CSV 컬럼

timestamp, device, keyword, ad_type(powerlink/powercontents), source(1page=첫 화면 / more=더보기 목록), rank, total(노출 광고 수, 파워컨텐츠 영역 없음이면 -1), site(광고주명), url(표시 URL), title, desc, ad_id, landing(랜딩 URL), target_hit(내 도메인이면 Y)

## 주의

- 순위는 시간대·입찰 경쟁에 따라 계속 바뀝니다. 같은 키워드를 여러 번 돌려 추세를 보세요.
- 너무 빠르게 많은 키워드를 돌리면 네이버가 자동화 접근으로 차단할 수 있습니다. `--delay`를 늘리세요.
- 네이버 페이지 구조가 바뀌면 추출이 안 될 수 있습니다 (`rank.py`의 `EXTRACT_JS` 수정 필요).
